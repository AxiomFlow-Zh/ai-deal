# AI猎手｜AI 订阅比价与优惠信息

[AI猎手](https://www.axiomflow86.qzz.io/) 是面向中文用户的 AI 订阅与工具报价聚合站。网站整理 ChatGPT、Claude、Cursor、Gemini、Grok 等产品的小铺公开报价、库存、交付方式、质保信息和风险标签，帮助用户在购买前完成横向比较。

![AI猎手网站预览](https://www.axiomflow86.qzz.io/assets/brand/og-cover.png)

## 在线访问

- 正式站点：<https://www.axiomflow86.qzz.io/>
- 备用入口：<https://ai-deal.axiomflow86.qzz.io/>

## 核心能力

- **AI 订阅聚合**：集中展示 ChatGPT、Claude、Gemini、Grok、Cursor 等商品。
- **同款比价**：按品牌、套餐、周期和交付方式整理多个公开报价。
- **库存与更新时间**：展示当前库存和数据更新时间，减少无效跳转。
- **风险提示**：标注账号归属、短效、地区限制、售后和质保等信息。
- **优惠资讯**：整理能够明确节省费用或获得高级权益的公开活动。

AI猎手仅聚合公开信息，不销售商品、不代下单，也不对第三方店铺或商品作安全背书。价格、库存、交付内容与售后规则可能变化，购买前请打开原商品页再次核验。
